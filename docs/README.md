# Documentation index

Documentation for the Radiation Safety RAG system. Start with the [root README](../README.md) for what the project is, what it covers and how to run it.

Each entry below says what a document is for and whether it describes the **current** system (kept up to date) or is a **historical** record (kept as written; may not match the code any more).

## Current reference

| File | Kind | Use it for |
|------|------|------------|
| [architecture.md](architecture.md) | Reference | How a question is answered: the LangGraph workflow with every node, chain and routing rule, the state, ingestion and the source catalog, document updates and Danish sync, LLM and embedding providers, privacy mode, API routes, saved eval runs, adding a node or chain |
| [production-readiness.md](production-readiness.md) | Reference / runbook | Deploying and operating: route exposure and admin auth, rate limiting, metrics, container hardening, CI workflows, runbook for common incidents |
| [releasing.md](releasing.md) | How-to | How release-please produces versions, tags and the CHANGELOG from Conventional Commits; how to merge each kind of pull request |
| [maintenance.md](maintenance.md) | Log | Dated log of the weekly dependency and security checks (newest first); append, do not rewrite |
